LAKSHIV OS - app package
========================

A Windows-style desktop that runs in your browser: Start menu, taskbar, windows,
File Explorer, Docs, Browser, Terminal, Paint, Settings and more.

Keep all of these files together in one folder.

Easiest (Windows):
  Double-click "Launch Lakshiv OS.bat". It opens Lakshiv OS in its own window
  (Edge or Chrome app mode). Right-click the .bat > Send to > Desktop (create
  shortcut) if you want an icon on your desktop.

Any computer:
  Open index.html in Chrome, Edge or Firefox.

Install as a real app (Chrome or Edge):
  1. Upload this whole folder to a GitHub repo and turn on GitHub Pages.
  2. Open the Pages link in Chrome or Edge.
  3. Click the Install icon at the right end of the address bar.
  It then gets its own window, a taskbar icon, and works offline.

Your files and documents are stored in the browser you use. Opening the app in a
different browser, or from a different folder or web address, starts with an
empty OS.

Inside Lakshiv OS you can also use the Start menu > Power (the power icon) > "Download Lakshiv OS..." to
save a fresh copy of the app at any time.
